# DAGLoop

**DAGLoop: Aligning Method Design with Experimental Feedback in Automated AI Research**

DAGLoop is a framework for testing method-design decisions with dependency-aware experiments and evidence-guided feedback in automated AI research.

The paper, implementation, and supporting artifacts are being prepared. Further materials will be released in this repository.
